\begin{abstract}
企业财务问题既可能要求比较收入，也可能要求从年报归纳业务举措。本实验检验同一 Agent 能否按题目选择查询、检索或计算，并将该流程用于新的公司。我们用 37 道开发题比较两种方案，再冻结配置，独立评测 19 道测试题。\FQAbstractCN
\par\noindent\textbf{关键词}\quad 企业财务问答、工具调用、年报检索、证据溯源
\par\medskip
{\normalfont\zihao{5}\noindent\textbf{Abstract}\quad
We built an agent that queries financial facts, searches annual reports and calculates metrics. We compared two retrieval configurations on 37 development questions, then froze the system and answered 19 questions about unseen companies. \FQAbstractEN
\par\noindent\textbf{Key words}\quad financial question answering, tool use, annual report retrieval, evidence provenance\par}
\end{abstract}
