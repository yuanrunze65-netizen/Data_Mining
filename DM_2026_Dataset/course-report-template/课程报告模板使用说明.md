# 数据挖掘导论课程报告 LaTeX 模板

## 排版规格

| 项目 | 规格 |
|---|---|
| 文档类 | `acmart`，选项为 `sigconf,nonacm,screen` |
| 编译器 | pdfLaTeX |
| 文本编码 | UTF-8 |
| 页面 | US Letter，215.9 × 279.4 mm |
| 正文布局 | 双栏 |
| 标题与作者区 | 跨双栏，中文标题、三位中文作者及单位 |
| 作者区下方附加间距 | 8 mm，由 `\ReportAuthorBottomSpace` 设置 |
| 页眉 | 所有页面居中显示“数据挖掘导论课程报告2026年” |
| 页码 | 页脚居中，阿拉伯数字 |
| 摘要与关键词 | 中英文分别设置 |
| 目录 | 不显示；章节提供 PDF 书签 |
| 参考文献 | BibTeX，`ACM-Reference-Format` 样式，数字编号引用 |

## 字体资源

字体文件位于 `fonts/`，通过相对路径加载，无需安装 Office 或向操作系统安装字体。

```text
fonts/
├── Simsun.ttc                  宋体
├── SimHei.ttf                  黑体
├── Kaiti.ttf                   楷体
├── times.ttf                   Times New Roman 常规体
├── timesbd.ttf                 Times New Roman 粗体
├── timesi.ttf                  Times New Roman 斜体
├── timesbi.ttf                 Times New Roman 粗斜体
├── report-ec-unicode.enc       Times New Roman 编码向量
└── report-times-map.tex        Times New Roman 字体映射
```

中文使用 CJK/zhmetrics 的 Unicode 子字体映射，英文使用 T1 编码、预生成度量及虚拟字体。
字体以矢量形式嵌入 PDF。正常编译无需执行字体生成程序，也无需启用 shell escape。

## 本地编译

需要安装包含 `ctex`、`CJK`、`zhmetrics`、`bm`、`algorithm`、`algpseudocode`、`tikz`、`pgfplots` 和 `placeins` 等宏包的 TeX Live 环境。

在工程目录执行：

```sh
./build-course-report.sh
```

也可以使用 latexmk：

```sh
latexmk -pdf -outdir=build-course-report course-report.tex
```

编译脚本自动运行 pdfLaTeX、BibTeX 和所需的重复编译，并将结果保存为工程目录中的 `course-report.pdf`。
使用编辑器时，将主文件设为 `course-report.tex`，编译器设为 **pdfLaTeX**。

## Overleaf 

1. 选择 **New Project → Upload Project**，上传完整的模板 ZIP。
2. 将 **Compiler** 设为 **pdfLaTeX**，**Main document** 设为 `course-report.tex`。
